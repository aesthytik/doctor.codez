# Fonts for the link-preview picture

`app/og.png/route.tsx` draws the picture shown when the site is shared, and needs the
fonts as files. (The page itself loads the same families through `next/font`.)

| File | Family | Source |
|---|---|---|
| `BigShoulders-Black.ttf` | Big Shoulders Display, weight 900, Latin | Fontsource |
| `InstrumentSerif-Italic.ttf` | Instrument Serif, italic, Latin | Fontsource |

Both are published under the SIL Open Font License 1.1 (<https://openfontlicense.org>).
